# Folder Lagu Perpisahan Logout

Anda dapat memasukkan file lagu favorit Anda (format MP3) ke dalam folder ini dengan nama:
`farewell.mp3`

### Fitur Audio & Layar Logout (Durasi 1 Menit):
1. **Durasi Otomatis 1 Menit**: Layar logout kini dirancang khusus untuk menikmati lagu berdurasi ~1 menit (60 detik) lengkap dengan *countdown progress bar* dan alunan memori.
2. **Auto-Detect Durasi**: Sistem otomatis mendeteksi durasi asli dari `farewell.mp3` jika durasinya lebih atau kurang dari 60 detik.
3. **Tombol "Sudahi Galau & Masuk Login"**: Pengguna dapat melewati lagu kapan saja dengan mengeklik tombol tersebut tanpa harus menunggu 1 menit selesai.
4. **Instrumen Cadangan (Web Audio API)**: Jika `farewell.mp3` belum dimasukkan, melodi kotak musik romantis (*music box arpeggio*) akan otomatis mengalun lembut secara berulang (looping) selama 1 menit.

Rekomendasi potongan lagu:
- **The 1975 — About You** (Menit `03:41` – `04:41` untuk durasi 1 menit penuh, mencakup bridge vokal Carly Holt hingga outro).
